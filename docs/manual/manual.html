What Captioner does

Captioner is the tool between the memory card and Lightroom. You review the photos of a game, rate them, pick the keepers and caption them. Then you drag the selection into Lightroom, which takes over headline, caption, keywords, stars and color on import.

What makes it special are codes: instead of “-23- Max Muster (EC Bad Nauheim)” you type #bn23#. Captioner suggests players as you type, inserts the full name when saving and adds the person to the tags automatically. The codes live in roster files that a team maintains once and everybody uses.

A typical workflow:

  1. Open a folder, e.g. the image folder on the memory card.
  2. Review and rate: preview, stars, color classes, tags.
  3. Choose a template: location, photographer, copyright and suffix for the game.
  4. Enter the headline, e.g. DEL 2 - EC Bad Nauheim gegen Bietigheim Steelers.
  5. Caption image by image, using codes for the players.
  6. Drag into Lightroom.

Your files are safe. Captioner never changes RAW files (NEF, CR2, ARW …); everything goes into an XMP file next to them. JPG, DNG and TIFF are written via a copy that only replaces the original once the image data has been verified to be unchanged. More under Handing over to Lightroom.

Installing and starting

macOS

Captioner runs on Macs with Apple silicon (M1 and later) with macOS 26 or newer. There are two ways to install it:

  • Disk image (DMG): open it and drag Captioner onto “Applications”.
  • Installer package (PKG): double-click it and follow the assistant.

On first launch macOS may say that the app cannot be opened because it is not notarized by Apple. In that case open System Settings → Privacy & Security once and click “Open Anyway” at the bottom. After that the app starts normally.

ExifTool, which Captioner needs to read and write metadata, is built in.

Windows

Run the installer Captioner-…-x64-setup.exe. It installs for all users or, without administrator rights, just for you. Optionally it creates a desktop icon and the entry “Open with Captioner” in the context menu of folders and drives.

Windows SmartScreen warns on first launch because the installer is not signed: “More info” → “Run anyway”.

Windows differences: wherever this manual says ⌘, use Ctrl on Windows; ⌥ is Alt. Some shortcuts differ (see Keyboard shortcuts). Spell checking is only available on the Mac.

Updates

At most once a day, Captioner checks for a new version on startup. If there is one, “Update … available” appears at the bottom right; a click opens the download page. To check by hand: Help → Check for updates ….

Language

Captioner follows the system language (German or English). You can choose it in the settings. Help → Manual (PDF) opens this manual in the language of the interface.

The window

Tabs
Every open folder has its own tab, with + on the right for a new one. The tab shows the name of the memory card and of the folder.
Filter bar
Folder path and number of images, filters for tags, stars, colors and “uncaptioned only”, below that the search field and the time filter.
Gallery
All images of the folder as tiles, sorted by capture time. A tile shows the file name, the file type (RAW+JPG with the same name are one tile), the tag checkbox, stars and, as a colored frame, the color class. A pencil icon means the image is captioned.
Caption panel
Template, headline, caption with preview, tags, city and location. At the bottom Save and “Save & next”, copy/paste of the caption and the roster status.
Status bar
Number of images and of selected ones, hints, the “Preview” slider for the tile size and, at the far right, whether everything is saved.

On the Mac the menus are in the menu bar at the top of the screen: Captioner (About, Settings, Quit), File (Open folder, Reload, Rename images, Close tab, Customize keyboard shortcuts), Edit (Undo, Redo, Find and replace), Template, Roster and Help (Manual, Keyboard shortcuts, Website, Updates).

Folders and tabs

Opening folders

There are several ways:

  • ⌘O or File → Open folder …. In the dialog, ⌘-click or ⇧-click selects several folders at once.
  • Double-click into the empty gallery while no folder is open yet.
  • Drag folders from Finder or Explorer onto the window.
  • Drag folders onto the Captioner icon in the Dock, or right-click in Finder and choose Open With → Captioner. On Windows: right-click → “Open with Captioner”.

Captioner reads JPG, NEF and other RAW formats, DNG and TIFF.

Opening a whole memory card

If a folder contains no images itself but subfolders with images (the card itself or DCIM), every image folder opens in its own tab. Drop two cards onto the window and all image folders of both cards are open right away. With more than eight folders, Captioner asks first.

If you prefer everything in one tab, turn on “Include subfolders” in the settings.

Working with tabs

  • Each tab has its own gallery and selection. Filters and the caption panel apply to the active tab.
  • Switch: click the tab or press ⌘⌥→ / ⌘⌥←. Close: ⌘W or the cross on the tab. Tabs can be reordered with the mouse.
  • Right-click a tab: Close tab, Close other tabs, Close all tabs.
  • A folder that is already open is not opened twice but brought to the front.
  • The tabs are back on the next start. Missing folders (card not inserted) are skipped.
  • F5 reloads the active folder, e.g. after images were added outside Captioner.

Reviewing: gallery and preview

Gallery

A click selects an image, ⌘-click and ⇧-click select several. The arrow keys move through the gallery, Home and End jump to the first or last image. ⌘A selects all, ⌘D clears the selection. The “Preview” slider at the bottom right sets the tile size.

Preview

Space or a double-click on a tile shows the image large; Space, Esc or ⌘W closes it again. ← and → move to the previous or next image. Stars, color classes and tags work with the same keys as in the gallery.

Zoom:

  • Z or * switches between “fitted” and 100 %.
  • + and - zoom in steps (50 to 400 %), the slider at the bottom continuously.
  • ⌥ + scroll wheel or a double-click zooms at the mouse position, ⌘ + click zooms to the spot and centers it.
  • When zoomed, drag with the mouse, use the scroll wheel or ⌥ + arrow keys (faster with ⇧) to move the visible area.

Zoom and visible area are kept when you move to the next image, so you can compare the sharpness of a burst at the same spot. 100 % is the full resolution of the preview embedded in the file; for Nikon NEFs that is the full sensor resolution.

Below the image you see the file name, tag, stars and color class, and at the very bottom the camera, lens, focal length, shutter speed, aperture, ISO and the files of the image, e.g. NIKON Z 9 · NIKKOR Z 70-200mm f/2.8 VR S · 200 mm · 1/500 s · f/2.8 · ISO 64 · DSC_0001.NEF.

Info panel: on the right are the image's EXIF and IPTC data: capture time with hundredths of a second, camera and serial number, lens, exposure, GPS, the caption and the files that belong to the image. “Info” hides and shows the panel; Captioner remembers your choice.

Captioning in the preview: I or “Caption” brings the caption panel next to the image and puts the cursor into the caption. ⌘N / ⌘B save and show the next or previous image large. While you type, digits, T, Z, +, - and the space bar do nothing else; a click on the image hands the keys back to the preview.

Everything applies to the selection, so also to many images at once, and can be undone with ⌘Z.

  • Color classes show as a colored frame around the tile. Classes 1–5 are also written to the file as Lightroom color labels: red, yellow, green, blue, purple. The names must match your Lightroom (see Settings).
  • Stars become the rating in Lightroom.
  • Tags are a marker for picking images, e.g. “goes into the gallery”. ⌘T selects all tagged images; F3 shows only tagged ones, F4 only untagged ones (press again to show all). Lightroom does not know tags.

Context menu of the tiles

Right-clicking a tile opens a menu for the selection. If you click an image that is not selected, only that one is selected first (as in Finder).

It contains Rating and Color class (submenus, the current value is checked), Tagged, Preview, copy and paste caption, Copy to tab, Show in Finder (Windows: in Explorer), Copy path and Move to trash. Each entry shows its keyboard shortcut on the right.

Searching and filtering

  • Search field: finds words in the file name, headline, caption and tags. With several words, all of them must occur.
  • Tags, stars, colors: e.g. “★★★ and more” or “no color”.
  • uncaptioned only: shows the images that have no caption yet.
  • Camera: appears when the folder contains images from several cameras. Two bodies of the same model are told apart by serial number (“NIKON Z 9 · …1234”).
  • Time: shows only images from a time span, e.g. one period. When you turn it on, the span of all images is preset.

The filters apply to all tabs; when you switch tabs they act on the new one.

Captioning

The fields

Template
Provides location, photographer, copyright, extra tags and the suffix appended to the caption. See Templates.
Headline
The game in the format <occasion> - <home> gegen <away>, e.g. DEL 2 - EC Bad Nauheim gegen Bietigheim Steelers. The word gegen stays German in the English interface too, because the later player recognition reads exactly that. If the headline deviates, the panel warns but still saves. An image without a headline takes the last one saved. Codes work in the headline as well, e.g. DEL 2 - #bn# gegen #bi#.
Caption
What happens in the picture, with codes for the people. Below it the preview: this is how it will be saved, including the suffix and the people who go into the tags.
Tags
Keywords, separated by commas. While you type, Captioner suggests words you have used before. People from the codes and the template's extra tags are added when saving.
City, Location
From the template or by hand; Map … looks the place up on a map (see Location, map and GPS).

Typing codes

A code sits between two hash signs: #bn23#. As soon as you type #bn, a list of matching players opens; the two teams from the headline are at the top. Arrow keys and Enter accept a suggestion.

Input

Battle between #bn23# and #bi99# in front of the goal

Saved as

Battle between -23- Max Muster (EC Bad Nauheim) and -99- John Doe (Bietigheim Steelers) in front of the goal, DEL 2 - EC Bad Nauheim gegen Bietigheim Steelers, Bad Nauheim, Colonel-Knight-Stadion, 18.10.26

Tags

Max Muster, John Doe, Ice hockey, DEL2

Known codes are highlighted green in the text, unknown ones red. An unknown code blocks saving, so a code never ends up in the file instead of a name. The resolved text is always what gets saved; Captioner remembers the text with codes so you can edit it later.

Saving is instant; the files are written in the background. The bottom right reads “everything saved” once all files are written. Below the caption Captioner counts the bytes: IPTC allows at most 2000 bytes for the caption. If a field is too long it turns red and saving is blocked.

Several images at once

With several images selected, headline, tags, city and location apply to all of them. The caption is only taken over if you changed it in the field; otherwise every image keeps its own.

Carrying a caption from image to image

⌘⇧C (or “Copy” in the panel) copies headline, caption, tags, city and location, including what is not saved yet. ⌘⇧V (or “Paste”) pastes into all selected images and saves. The codes are resolved again per image, and the suffix gets the date of the target image.

Spelling (macOS)

Typos in the caption are underlined in red, using the same dictionaries as Mail or Pages. Codes and names from the roster don't count as mistakes. A right-click shows suggestions, “Learn spelling” (then also applies in other apps) and “Ignore”. Choose the language in the settings.

Templates

A template holds everything that is always the same for a game or an arena. You choose it at the top of the panel; Edit … next to it opens it.

Headline
Usually empty: then you enter the headline in the panel, and the template works for every game. With a fixed headline it fits exactly one game.
Date
Normally empty, then the suffix contains the capture date. To prepare ahead (today for Sunday) enter a fixed text such as 18.10.26; if it doesn't match an image's capture date, the panel shows an orange warning.
Location
City, location/arena, state, country, country code (three letters, e.g. DEU). “Map …” fills city, location, state and country in one go.
Creator and rights
Photographer, photographer's email, position, credit (how the credit line should be printed), caption writer, copyright, copyright URL, source, instructions (e.g. contact and bank details).
Category, extra tags
Extra tags go into every image, e.g. Ice hockey, DEL2.
Suffix
Text appended to every caption, with placeholders such as {headline}, {city}, {sublocation}, {date}, {creator}, {copyright}. Clicking a placeholder in the legend inserts it, “Result” shows the finished suffix. Empty placeholders are dropped together with their comma.

Filled fields are written into every image when saving. Empty fields keep the image's value, e.g. photographer and copyright the camera has already entered.

Applying a template to the selection

“Apply template to selection” (⌘⌥A) sets headline, location, rights and tags for all selected images. With “Overwrite content” (on by default) everything is reset to the template and existing captions are cleared; without the check mark the captions stay.

Managing templates

In the Template menu and under ⋯ next to the selection:

  • New template … and New template from the selected one … (a copy, e.g. for an away game; Cancel discards the copy).
  • Create template from photo … turns the caption of the selected photo into a new template, e.g. from an image already captioned in Lightroom. Headline, location, creator and rights are taken over, the keywords (without people, teams and city) become extra tags, and Captioner recognizes the suffix from the end of the caption, e.g. , {headline}, {city}, {sublocation}, {date}. The dialog opens for you to check; nothing is saved before OK.
  • Load template file … adds a file from anywhere on the computer, e.g. from a colleague (or drag the .toml file onto the window). It stays linked: changes are written back to exactly that file.
  • Save template as … writes the template to a new file, e.g. to pass it on.
  • Show template folder in Finder shows where your own templates are stored.
  • Remove from list: files outside the template folder are never deleted.

Rosters and codes

A roster is a text file with one line per code: the code, a tab, then the text to insert. Lines such as - EC Bad Nauheim - are section headers for a team.

- EC Bad Nauheim -

bn23	-23- Max Muster (EC Bad Nauheim)
bn9	-9- Tom Platzhalter (EC Bad Nauheim)

- Bietigheim Steelers -

bi99	-99- John Doe (Bietigheim Steelers)

- Teams -

bn	EC Bad Nauheim
bi	Bietigheim Steelers

People are written as -number- Name (Team); that is how Captioner recognizes them and adds the name to the tags. Team codes such as bn can be used in the headline.

Sources

Rosters come from web addresses (URLs), from files on the computer or both. Roster → Add roster file … adds a file, or drag the .txt onto the window. In the settings you can add, remove and reorder sources. If the same code has different texts in two sources, the upper one wins and Captioner shows the conflict. Without internet, Captioner uses the last version of a URL it loaded. “Reload roster” fetches all sources fresh.

Editing rosters

Roster → Edit roster … opens an editor for the roster files on the computer. Tabs are highlighted blue. Lines that would be ignored when loading (space instead of tab, missing text) and contradictory duplicate codes are marked red and listed at the bottom; a click jumps to the line. ⌘F searches, ⌘S saves. Files are saved in their own character encoding, so rosters created on Windows stay intact.

Location, map and GPS

Map … next to “City” (in the panel and in the template) opens an OpenStreetMap map:

  • Search: type an address, postcode or venue, e.g. Colonel-Knight-Stadion, then Enter. The map jumps there and fills city and location. With several results, choose the right one.
  • Click: a click sets the point; city and location are looked up for it. Dragging moves the map, the scroll wheel zooms.
  • City and location can still be changed before you confirm with OK.

Every chosen place is remembered. When you type in “City”, Captioner suggests remembered places, even without internet. Without a connection the dialog shows a notice instead of the map; you can still enter city and location.

GPS

If the chosen place has coordinates, Captioner writes them into the file as GPS position when saving; Lightroom shows them in the Map module. This happens only for images without GPS: if the camera recorded GPS itself, it is left untouched. The note below “Location” says what will happen.

Captioner uses OpenStreetMap for the map. Searching only starts on Enter, at most once per second; the search text or the clicked point is sent to openstreetmap.org.

Find and replace

Edit → Find and Replace … (⌘⌥F) replaces text in the selected images, or in all shown images if nothing is selected.

  • Choose from caption, headline, tags, city and location; plus “Match case” and “Whole words only”.
  • In the caption, the search runs on the text with codes. #bn9# → #bn10# therefore swaps the player including the person tag. A written-out name is found even where the text has a code.
  • The template's suffix is not searched but rebuilt.
  • Images where an unknown code or a field that is too long would result are locked.
  • ⌘Z undoes everything in one step.

Undo

⌘Z undoes the last change: stars, color class, tag, saved caption, paste, apply template, find and replace, also for many images at once. ⌘⇧Z redoes it. The Edit menu shows what will be undone. In a text field ⌘Z applies to what you just typed.

Moving to the trash (get images back from there in Finder or Explorer) and renaming cannot be undone.

Handing over to Lightroom

Drag the selected images into the Lightroom grid. Lightroom opens the import dialog and takes over headline, caption, keywords, stars, color label, location, rights and GPS.

Before dragging, Captioner writes everything that is still pending. Images whose metadata is not safely stored (write error, or a captioned RAW file without an XMP file) are left out of the drag; Captioner tells you which ones.

Where the metadata goes

Filewhere to
NEF, CR2, ARW, … (RAW)Into the XMP file next to it, <name>.xmp. The RAW file is never changed. An existing XMP file (also .XMP from another program) is updated.
JPG, DNG, TIFFInto the file itself (IPTC, XMP, EXIF). Captioner writes to a copy that only replaces the original if the image data is unchanged.

The XMP files are included in the drag (can be turned off in the settings).

Copy, rename, trash, Finder

Copying between tabs

Drag images from the gallery onto another tab (hovering over it briefly switches to it, so you can also drop them into its gallery), or use Copy to tab in the context menu. RAW, JPG and XMP file are copied together, with all saved metadata. The source stays as it is.

If a file already exists in the target, Captioner asks: Skip, Rename (DSC_0001-2.NEF + -2.JPG + -2.xmp) or Replace, optionally for all remaining ones. Cancelling never leaves half-written files behind.

Moving to the trash

⌘⌫ (Windows: Del) or the context menu moves the selected images to the trash after asking, with all their files (RAW, JPG, XMP). Nothing is deleted permanently; the images can be restored from the trash.

Renaming images

File → Rename images … renames all images of the folder in the current tab. The dialog has one field for the name, e.g. 20261023_MEM_EPC; Captioner appends the number (20261023_MEM_EPC_001). What the name looks like is up to you. It suggests the name you used last with today's date in front (YYYYMMDD), the first time just the date.

Numbering starts at 1 in order of capture time, padded with zeros to three digits (001 to 999, four digits beyond that). RAW, JPG and XMP file of an image get the same number, the extensions stay. If one of the new names already belongs to another file in the folder, nothing is renamed. Captions, stars and color classes are kept.

Show in Finder, copy paths

⌘⌥R or the context menu opens the folder in Finder (Windows: Explorer) and selects the file. “Copy path” puts the file paths of the selection on the clipboard.

Customizing shortcuts

File → Customize keyboard shortcuts … lists all actions. Choose an action, then Change … (or double-click) or Add …, and press the new combination. The field shows what is currently pressed; at most three keys together, e.g. ⌘⇧K.

If the combination is already taken, the dialog says so; it is removed there when you confirm. Changed actions are shown in bold. “Default” and “Reset all to defaults” restore the standard assignment. New shortcuts take effect immediately.

Questions and problems

Save is greyed out.
There is an unknown code (red in the text) or a field is too long (red below the caption). Fix the code or add it to the roster and choose “Reload roster”.
A code is not recognized although it is in the roster.
Usually there is a space instead of a tab between code and text. Edit roster … marks such lines red. For URL sources: “Reload roster”.
Lightroom doesn't show the color label.
The label names in the settings must match the color label set in Lightroom (German Lightroom: Rot, Gelb, Grün, Blau, Lila). Classes 6–8 have no Lightroom label.
Images are missing when dragging.
Captioner only drags images whose metadata is safely written and names the others. Often a captioned RAW file lacks its XMP file, e.g. because the folder is read-only (locked memory card).
The panel warns about the headline.
The headline doesn't follow the format <occasion> - <home> gegen <away>. It is saved anyway, but the later player recognition can't match the game. “gegen” stays German in the English interface too.
The map stays empty.
Without internet the dialog shows a notice instead of the map. Remembered places are still suggested when you type in “City”.
A shortcut does nothing.
F1 shows the current assignment. Gallery shortcuts such as T or digits only work when the gallery has the focus, not while typing in the panel. If in doubt, use “Reset all to defaults” in Customize keyboard shortcuts.
Where are settings and templates stored?
macOS: ~/Library/Application Support/captioner/, templates in the subfolder templates. Quickest way there: Template → Show template folder in Finder.
